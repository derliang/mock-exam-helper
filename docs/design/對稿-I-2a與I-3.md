## 差異清單

嚴重度：高＝資料或行為錯、會誤導使用者；中＝看得出的版面或顏色規則不符；低＝文字、細節。
「一眼修」＝改幾行就好、不涉及結構，可直接派。

## 座位表與標籤的班級色

- 步驟③ 班級卡（6 班）、步驟⑤ 座位表預覽：淺色、深色、375、1280 都有班級色，字與底對比清楚，班級字一律有印（不只靠顏色）；色相與 tokens.css 一致（溫紫、良洋紅、恭青綠…）。
- 步驟⑥ 標籤預覽（B4，淺深色、375／1280）：白底、不用班級色、班級靠「班｜姓名」文字分辨，符合 DESIGN〈紙面版面〉；在深色模式下紙面仍維持白底。
- **沒能與稿並排**：稿的「學測第三次」步驟⑤⑥ 示範停在「排座失敗／不能下載」狀態，沒有座位表與標籤可並排，只能對照 DESIGN 與 tokens。示範資料沒有 X／＋ 標示考生，**有標示的淡黃標籤格沒看到**。

## 需要決定的事（請調度員轉使用者或裁示）

1. **全科缺考要不要算一筆差異、強制選擇（C-7）**：稿要求選；實作有預設（列入缺考清單）、不擋。我的建議：**改稿採用實作**——強制選會讓所有已有全科缺考者的舊考試突然多一筆待處理。
2. **「組別不同」要不要給「手動編輯」（C-8）**：我的建議：**改稿採用實作的兩選一**——手動編輯只能改班級、座號、姓名，改不到組別。
3. **按鈕字「套用選擇」或「套用 N 筆核對結果」（C-5）、外觀鈕「外觀」或目前模式（A-8）**：建議都改稿採用實作的寫法。
4. **「以學生名單為準」會丟掉 X／＋ 標示（C-9，I-3 已知限制，調度員請我判斷）**：**要改**。目前選了之後，原本在考試名單上寫「X英聽」等個人標示的人，考科會被組別預設蓋掉，排座時被排進他不考的科目，而畫面完全沒提示。建議兩段：
   - 先擋風險（小）：在「以學生名單為準」選項下加一句提示「這位考生的考科會改用學生名單組別的預設；原本考試名單上的 X／＋ 標示會清掉，請到 ④ 或個別覆寫確認」，並在套用後的結果訊息列出受影響的人。
   - 正解（中）：匯入時把每位考生的 X／＋ 原始標示存在考試名單那一筆，改組別時「新組別預設 ± 個人標示」重算。這是資料結構變更，要派施工。
5. **A-1 改稿**：摘要列 820 寬跑版是稿與實作一起錯，修正要改稿（升 v2.35、重發成品），請同意後我再改稿，實作同一條 CSS 由施工同步。
6. **A-3 每間教室的組別切換**：稿沒有這個控制項。是既有決定（補稿）還是要拿掉（改實作）？
