# 對稿-甲：實作 vs 稿（資料夾設定、考試列表、新增考試、步驟①、步驟②）

基準：`origin/main` cf67141，稿 v2.11（`docs/design/mockups/原型.html` 版面基準、`設計系統.html` 元件／資訊基準）。稿以定案為準，實作要改成一致。
方法：`scripts/compare-shots`（複製到暫存、改埠避免與其他對稿員撞埠）起 vite，headless Chrome 開稿與實作，淺色 375／1280 並排截圖（初始化、列表另有 820 與深色），並用腳本擷取兩邊的文字與按鈕尺寸逐項比對。所有資料為假資料（seed 的「甲生」「範例高中」），截圖在 `docs/design/實作對稿/截圖-甲/`（檔名＝頁名-寬度，左稿右實作）。

**重要前提：seed 的假資料造成的差異不算**（例如學測第三次的考科顯示成「數學＋英聽」、各班人數、學生名單 0 人、日期、考生數）。下列只列畫面與行為差異。
