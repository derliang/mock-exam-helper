# 整站比對：設計定稿原型 vs 實際實作

比對日期：2026-11-08。只讀比對，未改任何程式。
原型：`docs/design/mockups/原型.html`（唯一長相參考）。實作：`src/ui/App.tsx`、`src/ui/pages/*.tsx`、`src/ui/components/*.tsx`、`src/styles/app.css`。
不重列的已知差異：導覽列、班級資料、學校與表頭、復原按鈕、頁尾版權。
嚴重度：大＝使用者一眼看出不同或缺功能；中；小。實作端行號是該檔案的行號。
方法限制：只讀原始碼，未在瀏覽器裡實際渲染；凡是要看實際像素的（例如分段鈕是否撐滿）標「待查」。`ImportWizard.tsx`、`flow.ts`、`seating.ts` 沒有逐行讀，相關項目標「待查」。
CSS 事實：`app.css` 的 `.seg` 與原型相同（`display:inline-flex`，沒有 `justify-self:start`），`.field`、`.stack`、`.card.stack` 都是 grid。分段鈕直接放在 grid 容器裡時，容器會被撐到整列寬；原型的做法是外面包 `.row`（flex）。
