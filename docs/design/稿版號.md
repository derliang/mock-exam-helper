# 稿版號

成品頁（原型、設計系統）的 `<title>` 與頁首都標「稿 v2.N」，讓使用者一眼知道哪個是最新。

## 規則

- 格式「稿 v2.N」：2＝使用者審的第二版再經第二輪拉皮（PR #92）；N＝每次稿有變動就加 1。
- **改稿必升版號**：改 `docs/design/mockups/` 任一份稿之前，先升版號、更新本表，改完用同一檔路徑重發成品（網址不變）。
- 要改的地方：兩份稿的 `<title>`（「原型稿 v2.N」「設計系統稿 v2.N」）、原型頁首「稿 v2.N・日期」徽章、設計系統頁首同樣徽章、本表。
- **成品標題＝成品選單名稱**，格式「<名稱> 稿 v2.N」，改稿一併升。日期用台北時間。成品網址固定：原型 https://claude.ai/artifact/81FtjiDjgWXRqRekYhRZD3、設計系統 https://claude.ai/artifact/XUyTQr8XxGtgFKrBv3PTFY。
