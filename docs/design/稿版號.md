# 稿版號

成品頁（原型、設計系統）的 `<title>` 與頁首都標「稿 v2.N」，讓使用者一眼知道哪個是最新。

## 規則

- 格式「稿 v2.N」：2＝使用者審的第二版再經第二輪拉皮（PR #92）；N＝每次稿有變動就加 1。
- **改稿必升版號**：改 `docs/design/mockups/` 任一份稿之前，先升版號、更新本表，改完用同一檔路徑重發成品（網址不變）。
- 要改的地方：兩份稿的 `<title>`（「原型稿 v2.N」「設計系統稿 v2.N」）、原型頁首「稿 v2.N・日期」徽章、設計系統頁首同樣徽章、本表。
- **成品標題＝成品選單名稱**，格式「<名稱> 稿 v2.N」，改稿一併升。日期用台北時間。成品網址固定，見下方〈成品清單〉（2026-11-09 換帳號後重發，舊網址作廢，原因見清單下方）。

## 基準規則（使用者 2026-11-09 定案）

- **稿 v2.22 經使用者 2026-11-10 審核通過（使用者原話：「稿可以」），是實作的基準；之後以最新通過的稿為準。**（v2.15 曾是基準，已被取代。分科模擬考作法使用者預告會大改，到時回頭改稿升版號。）實作必須照稿。
- 實作過程若發現稿需要修正：**先回來改稿**（升版號、更新本表、重發成品），並在 commit 訊息註明「為什麼改版」；不可默默變更稿件，也不可不照稿件實作。
- 稿與實作不一致時一律視為缺陷：改實作對齊稿，或改稿並說明原因，二選一。
