# 完工記錄：H1 功能開關機制（`build/h1-feature-flags`）

## 做了什麼（對照派工）
| 項目 | 做法 |
|---|---|
| ① FEATURES 清單 | `src/ui/features.ts` 的 `BUILTIN_FEATURES`：領卷清單（含對卷）、考生查詢、出缺席記錄表、列印對位測試頁、會考快速模式（scope=bcct）；id、中文名、白話說明、適用範圍；預設全關 |
| ② 存 Settings | `Settings.features?: Record<id, boolean>`（`src/data/types.ts`）；隨 `settings.json` 存取；舊存檔沒欄位／沒寫的功能視為關（`isEnabled`） |
| ③ isEnabled＋hook | `isEnabled(id, { settings, examKind })` 純函式；`useIsEnabled(id, examKind?)` hook；`FeatureContext` 由 App 最外層提供 |
| ④ 設定頁 | 設定 →「選用功能」分頁：勾選清單、白話說明、會考專用標「（只用於會考）」；沿用既有 `check`、`stack` 樣式，沒有新色碼 |
| ⑤ 接入 | 註冊表 `registerFeature(id, { nav, exportItems, stepPanels })`；App 頂端導覽、匯出頁（Step6「選用功能的輸出」）、各步驟最下方面板都只取「已開啟」的項目；關閉時完全不出現 |
| 接入指南 | `docs/dispatch/H包接入指南.md` |

## 測試
- `npm run typecheck` 通過；`npx vitest run` 28 檔 231 個全綠（新增 `src/ui/features.test.tsx` 11 個）；`npm run build` 通過。
- 涵蓋：預設全關、舊存檔相容、會考專用在學測／分科／不在考試裡不顯示、用假功能驗證關閉時導覽／匯出項／步驟面板完全不出現、匯出頁關閉時不含「選用功能的輸出」、設定頁列出五項且預設未勾、存檔再讀回一致（用記憶體檔案系統跑 saveDoc／loadDoc）。

## 沒驗到
- 沒有在瀏覽器實際點過設定頁分頁與勾選（只用 renderToString 驗證輸出）。
- 沒有乾淨 clone 重跑（本機 worktree `npm ci` 後跑的）。
- 導覽的「頁面路由」由各 H 包自己加（沒有功能時 Route 沒有對應頁）；匯出項的 `run` 介面只用假功能驗證，真實輸出由 H3、H5、H6 驗證。

## 決定
- 預設全關、五項 id 固定（`pickup-list`、`student-lookup`、`attendance-sheet`、`print-alignment`、`bcct-quick-mode`）。
- 會考專用判斷用 `exam.kind === 'bcct'`；沒有考試脈絡（設定頁、列表）時視為不顯示（但設定頁清單仍列出供勾選）。
- 匯出頁選用項目可單獨匯出（不勾核心項目也能只匯出選用項）；`text/html` 走列印頁，其餘當檔案下載。
