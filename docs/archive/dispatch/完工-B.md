## 做了什麼

| 檔案 | 內容 | 決定 |
|---|---|---|
| `seating.ts` | 排座引擎，全域輪流：各教室依序、每排給輪到的下一班（班序跨教室延續），該班用完就在同一排接下一班；空位只出現在該組最後一間的尾端。D24 原文的比例分配已移除 | D73（取代 D24 比例分配）、D49、D72 |
| `validate.ts` | 驗證器：每人恰一座、座位存在且不重複、教室種類與組別、空位只在各教室最後、同班編號沿座位嚴格遞增、同排不同班不穿插 | D25、D69③、D72 |
| `exam.ts` | 主排座：國中部全體一組；高中部理組、文組各自排進同組別教室；預備教室不參與；排完一律走驗證器 | D9、D10 |
| `marks.ts` | 標示建議（標少數、接近一半要使用者裁示）與套用；英聽不參與；輸出只有抽象標記，不含顏色 | D5、D11、D12、D67 |
| `detach.ts` | 抽離分配：每科各自算、不同科可重用預備教室、同科考試與自習用不同教室；考試用同一引擎排座並驗證；自習依教室順序、班級、座號出名單；單人特例不佔預備教室、標註地點；覆寫對不上名單時警告 | D7、D23、D26、D27 |
| `stats.ts` | 每間教室：每班人數、總人數、各科考試人數（含抽離出去的人數與留在本教室考的人數）；抽離教室每班人數 | D40、D57 |
| `version.ts` | 資料版本碼：穩定序列化＋FNV-1a 64，輸出 `XXXX-XXXX-XXXX` | D66 |

## D24 驗證（舊座位表，本機唯讀，只看座位編號）

- **使用者裁示（調度員轉達，2026-11-08）**：採全域輪流（選項 A），不採比例分配（B），也不採國三最後一間依編號連續（C）。
- **吻合**：高三 E2 理組三間教室，全域輪流逐排完全重現（`golden.test.ts`）；E1 理組只差 `sample-analysis.md` 已記的人工例外；國三第 1～5 間吻合。
- **不吻合**：
  - 沒有任何一份舊表是「按比例分配各班到各教室」，各班在各教室的人數是輪流填排自然得出的。
  - 國三最後一間不是輪流，而是把各班剩下的人依編號連續排滿。D10 寫明「沒有最後一間教室特殊的獨立規則」，所以沒有另做這種排法。
  - E3 與 E1／E2 文組有已知人工調整，不採。
- **無法驗證**：舊表每間都剛好排滿，表上的空格是實體桌位缺口，所以驗證不了「空位在各教室尾端」。
- 黃金測試只放去識別化的版面結構：班級人數、每排有哪些深位、各排的編號區段，沒有姓名、學號或原始檔。
