## 與稿不同之處（PR 內同列）
1. **會考的 ④ 小字**：稿寫「組別對照表」，實作寫「會考沒有選考」，步驟欄為「不需要・會考沒有選考」。原因：既有規則「國中部不顯示『組別』字樣」（`juniorScan.test.tsx` 把關），稿的示範資料沒顧到這點。要不要以稿為準請裁示。
2. **「已儲存到資料夾」**：稿是模擬字樣。實作在使用資料夾授權的瀏覽器顯示；存檔失敗改顯示「尚未存妥（見下方提示）」；不支援資料夾授權的瀏覽器不顯示。
3. **摘要列「⑤ 還沒有排座結果」**：稿沒有這一項（稿的待處理只有 ①～④ 與具體問題）。實作保留它但歸為「尚未完成」（琥珀、排在後面），讓正常流程不會在還沒排座時被當成錯誤。
4. **摘要列沒有「預備教室座位不足」**：稿該項來自預備教室抽離需求計算（屬步驟③／教室那一包的資料）。本包把逐項結構與「需要／可用／缺少」欄位做好，目前只有「班級教室座位不足」帶數字；預備教室項目留給教室包接上。
5. **稿的「原型導覽」「稿版號」「原型・假資料」徽章、頁首 beta 徽章**：原型專用，不搬（G4）。頁尾 beta 徽章同理：實作已有「預發布版才顯示」的 `pf-pre`，正式版 v1.0.0 不顯示。
6. 稿的「↩ 回到 X（你是從那一步過來處理問題的）」列（`wsRet`）：本包沒加。目前站內只有從步驟進設定的流程，已有設定頁頂的「← 回到 …」；步驟頁沒有回原頁堆疊，不會用到。
