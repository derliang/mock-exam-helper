# 施工分包・第三批（選用功能；使用者 2026-11-08 討論定案）

> 來源：D75–D78（`../decisions.md`）。**狀態：已討論定案，尚未派工**，等 E、F、G 併入後再排。
> 寫給沒看過討論的人：這批的重點不是功能多，而是「**每個學校、每種考試要不要用，由使用者自選**」，核心流程保持精簡。

## 使用者原意（摘要）

- 領卷與對卷可以做，但不是每個學校都需要 → 做成選用。
- 快速模式適用國中會考，但高中考科是選考，不適用 → 只對會考提供。
- 重排差異報告不符現實（座位表排好印出後不會再動；印出前可微調）→ **撤回**。
- 出缺席記錄表不一定需要，但未來補考等考試用得上 → 選用，版面不綁死「模擬考」。

## 分包

| 包 | 內容 | 性質 | 依賴 |
|---|---|---|---|
| **H1 功能開關機制** | 設定頁新增「功能開關」勾選清單；開關存 `settings.json`；關掉的功能從導覽、匯出頁、步驟中**完全消失**；提供一個 `isEnabled(featureId)` 給各頁用。不做分級、角色。**其他 H 包都建在它上面** | 核心基礎 | G 包導覽 |
| **H2 常駐摘要列** | 每步驟頂端「考生 N／座位 M／空位 K／警告 X」＋一鍵跳到問題處。**與 G 包「前置條件檢查」是同一元件，由 G 包做，不在 H 重做** | 核心（不可關） | 併入 G |
| **H3 領卷清單（含對卷）** | A4：每間教室每科試卷、答案卡份數（含抽離與備用），由 `core/stats.ts` 延伸；對卷版面另議（見下「待細節」） | 選用，預設關 | H1 |
| **H4 考生查詢** | 輸入編號或姓名 → 顯示教室、座位（排－深位）、含抽離資訊 | 選用，預設關 | H1 |
| **H5 出缺席記錄表** | A4、每間教室一頁、照座位順序、列不考科目、每科一欄打勾（抽離考生各科教室不同）；**標題與欄位用「考試名稱」變數，不寫死「模擬考」**，日後補考可沿用 | 選用，預設關 | H1 |
| **H6 列印對位測試頁** | 一張測試頁，確認 100% 縮放、邊距 10mm 沒被裁掉 | 選用，預設關 | H1 |
| **H7 會考快速模式** | 沿用上次且檢核全過時：貼上考試名單 → 看檢核總覽 → 匯出，其餘步驟標「沿用上次」，有警告才展開。**開關只在會考出現，學測不顯示** | 選用，預設關 | H1、H2、G |

**撤回，不做**：重排差異報告（D77⑥）。

## 暫定判定（我方假設，可改，未經使用者確認）

- **快速模式的進入條件**：教室沒變、學生名單沒變、新考試名單人數與考生數相符、沒有未對應的科目標示，四項全成立才進入；任一不成立退回一般六步驟，並說明是哪一項。
- **預設值全部「關」**：使用者說「不一定需要」，沒指定預設值。
- **出缺席記錄表每科一欄**：因抽離考生各科教室不同。

## 待細節（派工前要補）

- **對卷**的實際作法使用者尚未說明（是依座位順序對點名單、還是依教室核對試卷份數？）。H3 開工前先問，不要猜。
- **補考是否成為正式考試類型**見 `decisions.md` 未決 12，**本批不處理**。

## 共同要求

同 `施工分包.md` 與 `品質關卡.md`：獨立 worktree、A 軌交 PR、`npm run typecheck`／`npm test`／`npm run build` 全綠並附指令與結果、公開 repo 只用假資料、完工記錄寫 `docs/dispatch/完工-<包>.md`。每個選用功能的測試要包含「開關關閉時，該功能在導覽與匯出頁都不出現」。

## 順序
