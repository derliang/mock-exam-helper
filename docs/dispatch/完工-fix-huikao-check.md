# 完工：會考不需匯入名單、步驟③ 狀態檢核回復（build/fix-huikao-check）

## 現況（改動前）
國中部會考新增後不匯入名單：② 顯示「未完成」，③ 狀態檢核只剩灰字「尚未匯入考試名單…」＋預備教室提示，容量檢核與數字消失，摘要列也寫「尚未匯入考試名單」。根因：D82 後 `classCapacity` 在 `examEntries().length === 0` 就回 `noList`；會考全員參加、不需匯入卻被同一規則擋。

## 做了什麼
1. **考生口徑集中一處**：`src/ui/seating.ts` 的 `examEntries`——會考（`kind==='bcct'`）沒匯入名單時，以共用學生名單（國中部）全體為考生、每人考全部科目；已匯入則以匯入為準（可記缺考，D79 `seatableEntries` 不變）。摘要列、③、⑤⑥、排座輸入都走這個函式，口徑一致。新增 `hasImportedList`；`seatingBlockers` 對會考不再擋「② 考試名單還沒有匯入」；快速模式「上一次會考」改用 `hasImportedList`，不受影響。
2. **② 會考**：顯示「全員參加，不需匯入」＋「仍要匯入考試名單」按鈕，狀態完成；學生名單空時改提示去匯入學生名單。高中部不變。
3. **③ 狀態檢核回到原型**：頁面上方加統計列（考生／座位／空位或缺位／班級教室／預備教室，用既有 `StatsBar` 與 `.stats` 樣式，無新 CSS），其下狀態檢核卡：座位不足紅色「無法排座…請增加 N 個座位」、夠用顯示「多 K 個空位」；高中部理／文組分列、預備教室另算；會考顯示「會考沒有抽離，不需要預備教室」。高中部未匯入名單：不顯示考生 0（統計列顯示「—」），顯示座位合計與「匯入考試名單後檢核夠不夠」。完整警示仍只在頁面上方一則（10.7 規則 4）。
4. 沒動：Word 標籤／座位表匯出、`src/data/*`、版號、`app.css`（零改動）。
