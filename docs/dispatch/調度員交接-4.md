- 台灣繁體中文；**要使用者決定的事用問題卡**；每次回報附「我替你決定的事」；派工前先查額度與其他對話狀態，別重複派。

- 審 PR：乾淨 worktree，`npm ci` 後跑 tsc、測試、build，再 `gh pr merge N --merge`。推 `main` 的文件用 `git push origin HEAD:main`（pre-push hook 會跑測試，不跳 hook）。commit 作者用 `Claude-desktop <noreply@anthropic.com>`。

- 其他帳號看不到原帳號的對話與 `side-session-notes`；所需背景都在本 repo 文件裡。上列文件互相矛盾時，以 `稿版號.md` 與使用者最新指示為準。
