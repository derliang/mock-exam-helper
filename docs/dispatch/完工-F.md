## 不變式清單

主座位表
- **INV-1** 每位考生恰一座：人數相等、無重複、無遺漏、無多餘。
- **INV-2** 只在合法座位：教室存在且為班級教室、座標在可用座位內（空位後的座標不可用）、座位不重複。
- **INV-3** 高中部只坐同組別教室。
- **INV-4** 同班連續學號：沿座位順序嚴格遞增，且恰是該班名單（含跳號）。
- **INV-5** 空位只在最後：每間教室已坐座位為座位順序前段；同組別內，最後一間有人的教室之前都坐滿、之後全空。
- **INV-6** 同一排內各班各自連續、不穿插。
- **INV-7（失敗路徑）** 座位不足、預備教室不足時一定 `ok:false` 並說明，且只在這兩種情況失敗（獨立 oracle 判斷）；錯誤訊息不含姓名。

標示與抽離
- **INV-8** 標示完全由規則決定（不考→absent、加考→extra），英聽永不標，無重複。
- **INV-9** 抽離守恆：每筆標示恰好去一處（抽離考試／抽離自習／單人特例）；沒有多出的抽離；單人特例不被抽離、地點原樣。
- **INV-10** 抽離只進預備教室；考試有合法且不重複的座位，自習沒有座位且不超載。
- **INV-11** 同一科的考試教室與自習教室不重疊（D27）。
- **INV-12** 抽離考試座位空位只在最後、同班學號沿座位遞增。

輸出
- **INV-13** 每間班級教室一頁，頁上格子＝該教室 assignments，座標、編號、姓名逐筆相同；可用座位集合＝教室座位；統計總數與各班加總一致；全頁格數總和＝考生數。
- **INV-14** 每格標示數＝結果中該考生的標示數。
- **INV-15** 抽離考試座位表格子＝結果中的抽離考試座位。
- **INV-16** 標籤順序同座位表、人數相符；抽離名單列數＝抽離數＋單人特例數。
- **INV-17** Word（.docx 內文＋頁尾）與列印 HTML 中每個姓名出現次數＝版面模型，且沒有模型以外的姓名；每個座位／標籤頁都有資料版本碼。

往返
- **INV-18** 同樣輸入永遠同樣輸出；產生時間不影響資料版本碼；改名單／設定版本碼必變。
- **INV-19** `saveDoc → loadDoc` 完全相等；讀回資料重排，座位、標示、抽離、版本碼與存檔結果完全相同（不會誤報「過期」）。
- **INV-20** 內容不變不產生 `.bak`、改內容才有；主檔被竄改改讀備份並警告。
- **INV-21** 學生名單 → xlsx → 讀回 → `parseRoster`，班級、座號、姓名、學號逐筆相同。
- **INV-22** 考試名單（組別代碼，四次學測的表）→ xlsx → 讀回 → `parseExamList`，科目逐筆相同。
- **INV-23** 名單比對全部「以考試名單為準」或「以學生名單為準」後，兩份名單同編號同姓名、無重複、再比對零差異。
- **INV-24** 沒有差異的人，處理後科目不遺失。
