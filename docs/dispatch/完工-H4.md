# 完工-H4　考生查詢（選用功能 student-lookup）

分支 `build/h4-student-lookup`（從 origin/main `b9a534f` 起）。

## 做了什麼
- `src/ui/lookup.ts`（純函式）：`searchExaminees` 解析輸入——考生編號 4 碼／3 碼、「班級 座號」（`3 5`、`3-5`）、班級名稱＋座號（`良3`）、只有座號（各班同座號全列）、學號（對應學生名單 schoolId）、姓名部分比對；多筆全列供選；找不到回友善原因＋修法。`lookupExaminee`：每一科的教室、座位（排－深位）、抽離考試／抽離自習／單人特例／不考；單人特例以個別覆寫為準（D80）；全科缺考顯示「全科缺考，未排座」（D79）。
- `src/ui/pages/Lookup.tsx`：獨立頁；多次考試可選；沒排座結果→空狀態「先到 ⑤ 排座」；排座過期→警告；多筆同名→按鈕選一位。
- `src/ui/featureRegister/lookup.ts`：`registerFeature('student-lookup', { nav })`；`App.tsx` 頂端一行副作用 import＋路由一行；`nav.ts` 增 `{ page: 'lookup' }`。預設關，沿用 H1 機制。
