## 我替你決定的事（可推翻）
1. **全科缺考卡不擋排座、不計入「差異 N 筆」**：稿把它算一筆且全選完才能套用；但這項本來就有預設（列入缺考清單），強制選擇會讓所有已有全科缺考者的舊考試突然多一筆待處理。所以卡片放在比對頁、不計差異數、不必選。要照稿強制，需決定「未選」狀態存哪（目前 `seatFullyAbsent` 沒有「未選」）。
2. **「組別不同」只給兩個選項**：稿沿用三選一（含手動編輯），但手動編輯的欄位是班級／座號／姓名，改不到組別，沒有意義，故不給。
3. **新增班級的名稱**：考試名單只有班級序號沒有班名，先用「第07班」（`addClass` 既有預設），稿的「勇」是示範假名；可到共用設定改名。
4. 組別比較取首字大寫（「E」與「E-文組」視為相同）；學生名單的組別只有手動編輯或匯入才有，沒填就不偵測。
