## 與原型仍有的差異（誠實列出）
1. **預覽的標籤沒有班級底色**：原型預覽的標籤格有班級色，實作預覽直接用匯出的列印 HTML（`htmlRender.labelHtml`），那份目前沒有套班級色（資料模型有 `colorBg`）。標籤說明文字寫「每個班級一種底色」。這是匯出渲染器的問題，不屬本包範圍，建議另開項目（影響匯出一致性，與施工M 相關）。
2. 預覽是 iframe（縮放 0.38～0.5）而非原型的原生 DOM；座位表 A4 預覽在 iframe 內偏右（版面寬度由匯出 CSS 決定），未再追。
3. 步驟⑥的步驟外框（步驟標題卡、頁首、右側欄）屬版型，依派工規則等範本章，**沒有動**。「檢查通過」與錯誤警示的呈現未改。
4. 組別欄位在原型是「組別代碼＋名稱」（D-五科(數A.B.自)）下拉，實作是自由文字（資料裡沒有代碼對照表，且每次考試以考試名單為準）；若要做成下拉需先定義對照表來源。
5. 座號範圍：原型寫 1～60，實作驗證仍是 1～99（`store.validateStudent`，不是本包要動的）；表尾說明因此沒寫範圍。
6. 設定頁其他項目（部別切換位置、教室清單區塊、選用功能分頁）沒動；教室清單的控制項（RoomList、rooms.ts）依規定未碰。
