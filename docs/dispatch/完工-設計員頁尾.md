# 完工記錄：設計員「全站頁尾」（`design/footer-brand`）

## 做了什麼（原話 → 實作）
| 要求 | 做法 |
|---|---|
| 每頁底部標示程式名稱、版本、版權 | `src/ui/components/Footer.tsx`，掛在 `App.tsx` 外殼（所有頁共用，含初始化頁） |
| 版本號由 package.json 注入，不寫死兩處 | `vite.config.ts` 讀 package.json，`define` 注入 `__APP_VERSION__`、`__BUILD_DATE__`（台北時間）；`src/ui/version.ts` 格式化（`v` 前綴、beta 標示） |
| 只用 tokens、深色正常、手機不跑版 | 樣式在 `src/styles/app.css` 末段，只用變數；已在 375px 與深色實看，無橫向捲動 |
| 列印／匯出不受影響 | 匯出走獨立產生器，頁尾不在其中；`@media print` 隱藏 |
| 短內容頁貼底、不遮擋 | `#app` 改 flex 直欄、`min-height:calc(100dvh - 16px)`（扣 body 預設 8px 邊距，避免多出捲軸）、頁尾 `margin-top:auto` |
| 版本號可點開「關於」 | 沿用既有 `Modal`：版本、建置日期、版權、資料只存本機說明 |
| 測試、文件、成品頁 | `version.test.ts`、`Footer.test.tsx`（新增 devDependency `preact-render-to-string`，僅測試用）；DESIGN §10.1 新增一列；`mockups/設計系統.html` 新增〈全站頁尾〉 |
