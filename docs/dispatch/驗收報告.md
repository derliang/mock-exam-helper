## 二、缺陷清單

### D-1【重大】高中部：畫面完全沒有「教室屬於理組／文組」的設定，新使用者一定排不出座
- 重現：全新資料夾 → 設定匯入學生名單（高中部，班級 1–3 預設理組）→ 設定頁「教室清單」按「新增班級教室」×2 → 建立學測考試 → ② 匯入名單 → ③ 勾選這兩間教室 → ⑤ 按「開始排座」。
- 實際：③ 顯示「已完成」、座位 60 ≥ 考生 41、無任何警告；⑤ 才報「⛔ 排不出合規則的座位表：**理組沒有可用的教室**」。教室列、③、設定頁教室編輯都找不到可指定理／文組的控制項。
- 原因：`src/ui/rooms.ts` `addRoom()` 建立教室不帶 `track`；`src/core/exam.ts:52` 高中部依 `track` 過濾教室；`grep track` 在 `Step3.tsx`／`RoomList.tsx`／`rooms.ts` 沒有任何 UI。只有 `repository.ts` 的示範資料手寫了 `track: 'science'`，所以示範資料看起來正常。
- 證據：⑤ 錯誤截圖與頁面文字；我手動把 settings.json 的教室改成 `track:'science'` 後才能繼續（之後 7／7 驗證通過）。
- 建議：教室列加「理組／文組」分段鈕（高中部班級教室必填，預備教室不用）；③ 在未指定時就擋下並說明，不要拖到 ⑤。需調度員派工，屬於引路／資料欄缺口。

### D-2【高】匯出（Word／PDF）忽略「標少數」建議：座位表無 X 標示、沒有抽離自習名單，與畫面不一致
- 重現：接續 D-1 的資料，④ 完全不點（畫面顯示「標示都已決定，可以前往排座」，exam.json 的 `markRules` 為 `[]`）→ ⑤ 畫面座位表有「X國文」等標示、考生查詢顯示「0306 國文／社會＝抽離自習」→ ⑥ 匯出 Word。
- 實際：匯出的座位表 docx **0 個 X 標示**；勾了「抽離自習名單」卻**沒有產生該檔**（只出 2 個檔）；頁尾資料版本碼 `0866-7166-AFAE` ≠ 重新載入後 ⑤ 畫面顯示的 `3607-D790-3D51`（同一份資料）。領卷清單份數（國文 18 等）則與畫面一致，所以只有標示／抽離相關輸出被丟掉。
- 原因：`src/ui/exportInput.ts:40` 用 `markRules: exam.markRules`（只含使用者鎖定的規則），畫面端 `src/ui/seating.ts:113` 用 `effectiveMarkRules(doc, exam).rules`（鎖定＋「標少數」自動建議）。使用者若沒有逐科在 ④ 點選，匯出就與畫面走不同規則。
- 影響：違反驗收簡報第 3 項「畫面座位表與匯出的人數、座位逐筆一致」；正式監考時印出的座位表少了抽離標示，風險高。
- 建議：匯出改用 `effectiveMarkRules`；補一個「未鎖定也要一致」的測試（現有 F-5 回歸只覆蓋有鎖定的情況）；同時把 ⑤ 與匯出版本碼統一來源。

### D-3【中】標示未決時畫面宣稱「標示都已決定」，與實際寫入不符
- ④ 畫面顯示「✓ 標示都已決定，可以前往排座」且步驟列為「已完成」，但沒有任何規則被存下（`markRules: []`）。與 D-2 同源，修 D-2 時一併決定：要嘛自動建議也存檔並可見，要嘛 ④ 不要說「已決定」。

### D-4【低】關閉選用功能後，「← 回到 考生查詢」按鈕仍指向已關閉的頁面，且該頁仍可顯示
- 重現：開啟考生查詢 → 設定 → 選用功能全關 → 頁首「← 回到 考生查詢」→ 仍進入考生查詢頁。導覽列已正確移除，匯出頁的選用項目也正確消失。

### D-5【低】Word 罕用字（已知限制，未見提醒入口）
- 內嵌字型 Regular 的 cmap 共 13,968 個字：常用字、祐琇侑苡鈺禎崴煒嫻珮瑋龘均有；**堃、喆、峯與 𠮷、𧃍 無字形**（人名常見）。完工-D 已記載會退回使用者電腦字型，並有 `findMissingChars` 掃描（plan.ts:122）；本次未用含罕用字的名單走一遍 UI 確認警告實際出現，列為待查。

### D-6【觀察】

- 智慧匯入的科目欄表頭若寫單字「國」，沒有給「採用建議：國文」（其他欄名「英文」「社會」有）。

- 考試名稱輸入不進復原堆疊（復原計數維持 0）；教室勾選則可復原。若為設計即可忽略。
