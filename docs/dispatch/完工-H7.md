# 完工-H7　會考快速模式（選用功能 bcct-quick-mode）

分支 `build/h7-bcct-quick`（從 origin/main `f191f3a` 起）。

## 做了什麼
- `src/ui/quickMode.ts`（純函式）：`quickCheck` 判斷四項進入條件（教室沒變、學生名單沒變、新名單人數相符、科目標示對得上），回傳 unavailable／ready／passed 與逐項說明；`previousExam` 找上一次會考；`parsePasted` 把貼上的文字（Tab 分欄）解析成考試名單。
- `src/ui/pages/QuickPanel.tsx`：② 考試名單頁下方面板。條件不成立→「這次不能用快速模式，請照一般六步驟做」＋原因；成立→貼上框→「檢查並套用」→ 自動排座 → 其餘步驟標「沿用上次」→ 沿用 `flowOf()` 顯示檢核（無警告給「前往 ⑥ 匯出」，有警告才展開並附跳轉）。
- `src/ui/featureRegister/quick.tsx`：`registerFeature('bcct-quick-mode', { stepPanels: [step 2] })`；`App.tsx` 一行副作用 import。
- 接入點微調：`StepPanel.render` 多一個選用的 `onStep`（`features.ts` 型別一行、`App.tsx` 傳入一處），讓面板能引導跳步；原有功能不受影響。
- DESIGN.md 新增 10.8。
