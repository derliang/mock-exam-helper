# 待辦：節次功能（抽離與預備教室標籤納入節次）

> 2026-11-09 由節次研究討論員整理，給之後負責實作的人（使用者另外找人）。**全部尚未實作。** 結論與被否決的方案見 `docs/decisions.md` **D94**（補充並部分取代 D92，修正 D93 末句）；資料見 `docs/exam-schedule.md`〈學校模擬考實際節次〉。你沒看過當初的對話，這份就是交接。
> 公開 repo：不得出現任何真實學生姓名、學號、帳號。學校科目表與報名名單在使用者的雲端資料夾，**不進 repo**，要用先請使用者提供不含學生資料的版本。

## 先看這幾點（已定）
- 每科一個節次，同編號＝同一節。內建預設節次表，新增考試自動帶入、可改。
- **分科**：兩天各 4 節、共 8 節、一節一科、順序固定、每節 80 分。第一天 物理、化學、數甲、生物；第二天 歷史、地理、數乙、公民。114 下學期第 6 次（4/9）把兩天壓成一天、文理同節，是**特例**，不是預設。
- **學測**：一節一科，順序依學校科目表（與大考日程圖不同，內建照學校）。第 1、2 次第一天 英文、自然、國綜、英聽，第二天 數學、社會、國寫；第 3、4 次無英聽，第一天最後一節改數學 B，第二天 數學 A、社會、國寫。
- **會考**：順序與大考一致（第一天 社會、數學、國文、寫作；第二天 自然、英閱、英聽）；不抽離（D30）。
- 只看**考試時間與順序**，不管發卷與休息；開始與結束時間每次可能不同，**標籤不印時間**。
- **學測國文整個一起標**（一個標示涵蓋國綜與國寫兩節）。
- 加考同學的預備教室排座位有兩個模式，使用者可選，**預設模式 1**：模式 1 同學優先（同一人盡量每節同位，同班盡量遞增、每排輪替；遞增是「盡量」，是對 D3 的例外，驗證器只警告）；模式 2 監考優先（同班聚集，不保證同位，守 D3 硬規則）。
- 兩個模式都用**合併標籤**：預備教室每個座位一張，各節使用者列同一張、貼一次；標籤印「節次＋科目」，共用座位每節一行同字級。
- 抽離自習不排座位、不印標籤，只出名單（D7）。

## 流程（依專案四步流程，不可跳）
1. 設計員出稿並升稿版號（`docs/design/稿版號.md` 規則；改稿必升版號、重發成品）：節次欄位在哪頁輸入、預設表怎麼呈現與修改、兩個排座模式的選擇介面、標籤版面與字級、模式 1 的遞增警告文字、舊資料怎麼預設。
2. 使用者審稿通過。
3. 對稿員比對。
4. 施工 → 調度員審併 → 發布。
- **不併入**「依稿 v2.15 修正實作」那批。
- `docs/ast-spec.md` 由施工B 的 PR（#104～#106）維護，節次功能的人不要直接改它，需要改先問使用者。

## 實作項目（待設計員出稿後）
- [ ] **資料**：科目新增「節次」，內建預設節次表（學測第 1、2 次與第 3、4 次各一份、分科 8 節、會考 7 科）；時長與開始時間只當選填資料，標籤不印時間；舊資料沒有節次時的預設。
- [ ] **學測國文**：標示整個一起，但抽離與標籤要看國綜、國寫兩節；決定程式內是一個科目含兩節，或兩個科目 id 綁在同一標示；**必須與 D13、D67 一併檢查**。
- [ ] **抽離分配**（`src/core/detach.ts`，現行逐科算、不認節次）：改成依節次分組；同節抽離人數加總再比預備教室容量（預設表一節一科，這只在使用者自己把兩科改成同節時才會用到，但要支援）；同一節的考試抽離與自習抽離用不同教室（D27）；單人特例（D26）與會考（D30）行為確認不被破壞。
- [ ] **預備教室排座**：實作模式 1 與模式 2；模式 1 對 D3 的例外要在 `src/core/validate.ts` 對預備教室只警告、不擋匯出，模式 2 維持硬規則；座位不足時才讓不同節的人共用座位。
- [ ] **標籤**：預備教室每座位一張合併標籤，印節次＋科目、每節一行同字級、不印時間；現有標籤只有班座號（字級 180%～200%、依教室分區），這是新增。
- [ ] **檢核**：同一人同一節被標到兩科時報錯（預設表用不到，低優先，但使用者自改節次時會出現）。
- [ ] **測試**（假資料）：同一人跨節加考同座位；共用座位合併標籤；模式 1 遞增警告、模式 2 硬規則；同節加總容量不足；國文整個一起標；舊資料預設。
